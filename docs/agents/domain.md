# Domain docs

本仓库采用 single-context 领域文档结构：

- GLOSSARY.md：位于仓库根目录，记录领域术语。
- docs/adr/：记录架构决策。

## 阅读规则

探索代码前，读取已有的 GLOSSARY.md，
并阅读与当前工作相关的 ADR。

文件不存在时直接继续，不因缺失而阻塞，
也不提前创建空文件。
由 domain-modeling 在实际明确术语或决策时按需创建。

## 使用规则

命名、需求、测试和设计说明应沿用术语表中的定义。
发现术语缺口时，交由 domain-modeling 处理。

提案与已有 ADR 冲突时，明确指出对应决策和重新讨论的理由，
不能静默覆盖。
