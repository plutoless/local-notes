## Limitations and integration

Intermediate native probes exposed stale/background AX trees and unproven close/keyboard delivery; they are not guard passes. Failed probe logs/captures remain in this worktree's `build/issue51-attempts/`; the successful probe uses the production responder/application dispatch and observes the resulting modal instead. Spec review found that nested source/initiative detours cleared the home return context; the context is now captured/restored with those origins and complete source and initiative round trips are covered in workspace.txt. Source-unavailability injection waits for the reopened editor and source validation before removing the file.

Physical multi-device synchronization, VoiceOver and physical keyboard/pointer journeys were not executed. No persistence changes were made.
